# 真实案例｜北辰青年第四期第1组

*2026年11月第一周共创项目。公开版只保留任务组织与交付方法，原始问卷、成员联系方式与内部记录不随Skill发布。*

## 任务与成果

目标：完成小组亮相，介绍成员、团队特色、可提供的合作价值和联系方式，并举办让成员彼此了解的线上共创活动。

- 32张公开成员展示卡。
- 22份载体选择问卷中，19份倾向交互网站；团队选择网站作为主展示形式，PPT作为备用。
- 圆桌活动采用“美食破冰 → 云公寓 → 两个研发室 → 新品发布”的流程。
- 交付两款产品网页原型《回音结》《把感受剪成片》，以及五章节团队网站与共创故事。
- 网站正式上线：<https://beichen-group1-co-create.pages.dev/>。
- 2026年11月9日参与12组联合高光路演。

## 如何组织协作

**定目标：** 先决定“让其他小组认识我们、愿意来交流”的最终效果。

**拆成果：** 把网站拆为首页、成员、产品、共创故事、联系五块。把内容任务进一步拆成可独立提交的小件：短口号、简介、一张产品卡、时间线草图、测试反馈等。

**配协作：** 两位主要开发成员负责源码、整合和部署；其他伙伴根据意愿承担文案、视觉、产品描述、资料管理、PPT、记录和测试。通过统一入口交接素材。

**跟进度：** 用明确截止时间收件。开发出现不同视觉方案时，围绕原始风格、完整体验和展示稳定性选择公开版本；历史方案保留。

**验收：** 提交前检查成员信息、交互入口、素材、移动视口、展示连贯性。发布记录含13项单元测试、62项浏览器测试，Cloudflare正式部署的124项文件指纹一致。

## 从案例提炼的方法

1. 把目标写清楚，形式服务于目标。
2. 把任务拆成每个伙伴能独立完成的具体成果。
3. 技术和素材使用明确的交接入口，降低协作成本。
4. 真实状态有据可查，临近截止优先保证核心成果。
5. 分享时讲清成员如何协作，让团队经验可以被复用。

**数据说明：** 22份问卷中的19份倾向网站；32是展示卡数量。上述测试覆盖桌面与触屏模拟，完整真人可用性测试未包含在这些数字中。
